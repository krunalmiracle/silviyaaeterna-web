# Silviya Aeterna

Bilingual (Bulgarian and English) landing page for **Silviya Aeterna**, a YouTube-led personal
project about astrology, numerology, skincare, psychology-informed wellbeing, family and
children, and mental health.

The site is a single static page plus local assets. No database, no auth, no forms, no
tracking, no cookies, no external requests, no third-party runtime dependencies.

## Run locally

Requires Node 20+ (the server is plain TypeScript with type stripping) or Bun.

```bash
node server.ts          # http://localhost:3000
# or, with Bun (same command Docker uses):
bun run server.ts
```

Environment: `PORT` (default `3000`), `HOST` (default `0.0.0.0`).

## Test

```bash
npm test                # runs: node --test tests/
```

- `tests/server.test.mjs` boots the server and checks `GET /`, every referenced asset,
  404 behaviour, that `server.ts` / `PRODUCT.md` / `.impeccable/**` are never served, that
  every write method (including the removed AI editor endpoints) answers `405`, that path
  traversal is contained, and that the server source holds no secrets or outbound calls.
- `tests/content.test.mjs` is a static check of the page: no em or en dashes, no absolute
  URLs, no inline styles or scripts, complete EN/BG pairs, alt text on every image, working
  anchors, heading order, honest non-clickable coming-soon states, the accessible language
  toggle, and the reduced-motion / no-JavaScript fallbacks.

## Screenshots

```bash
uv run --with patchright python tools/shots.py http://localhost:3000 .impeccable/review
```

Writes `desktop.png`, `desktop-top.png`, `mobile.png`, `mobile-top.png` (1440 and 390 wide)
and prints a JSON report (console errors, failed images, horizontal overflow, language
toggle, reduced-motion visibility). The browser is closed when the script exits.

## Design and product documentation (development only)

- `PRODUCT.md` - product truth.
- `DESIGN.md` and `.impeccable/design.json` - visual system and tokens.
- `.impeccable/surfaces/index-html.md` - surface brief and direction contract.

These files are development artifacts. The server only serves `/` and `/assets/**`, so they
are never delivered to visitors.

## Assets

Every illustration is an original local SVG in `assets/`, generated by
`tools/generate_assets.py` (deterministic geometry, no stock, no hotlinks). Provenance is
recorded in `assets/PROVENANCE.md`. Regenerate with:

```bash
python3 tools/generate_assets.py
```

The typeface is a subset of **Geist** (SIL Open Font License 1.1), self-hosted from
`assets/fonts/` with `@font-face`. Nothing is loaded from a font CDN.

## Deploy

`Dockerfile` is unchanged in behaviour: `bun run server.ts` on port 3000, so the existing
Dokploy service keeps working. Dependencies were removed, so `bun install` is a no-op.
No changes were made to Dokploy, and nothing was pushed.

## Where to plug in the real links later

All future destinations are honest placeholders today: there is no YouTube account, no
social account and no Oriflame detail yet.

- **YouTube channel**: add the link in `index.html` inside `#channel`. Replace the
  `soon-state` span with an anchor and keep the label in both `data-en` and `data-bg`.
- **Social profiles**: add them to the footer nav in `index.html`. Do not add follower
  counts or testimonials; none exist.
- **Oriflame**: fill in `#shop` with confirmed product details, prices and links once they
  are supplied. Until then the section must keep its "Details coming later" state.
- **Open Graph image**: `og:image` is relative (`assets/social-og.svg`) because the public
  domain is not final. Set an absolute `https://...` URL when the domain is known, and
  optionally export `assets/social-og.svg` to PNG (1200x630) for platforms that ignore SVG.

## Content boundary

Everything on the page is educational and reflective. It is not medical advice, diagnosis
or treatment, and it does not replace a professional. The boundary is stated on the page
itself in the `#safety` section, in both languages.
